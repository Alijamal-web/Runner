

# Unity Runner Game

## About the Project

This project is a 3D endless runner game developed using Unity and C#. The project was created to gain practical experience in game development, programming, game mechanics, collision detection, and scoring systems.

The game features a player-controlled character, obstacles, collectible items, a shield power-up, a main menu, and a scoring system.

## Features

- **Endless Gameplay:** The player runs continuously while the score increases over time.
- **Obstacles:** Obstacles challenge the player, and collisions without protection end the run.
- **Shield Power-Up:** A shield protects the player from obstacle collisions.
- **Collectible Items:** Collectible items add five points to the player's score.
- **Scoring System:** The score increases over time and through collecting items.
- **Main Menu:** An interactive menu with Play and Exit buttons.

## How to Run

1. Download the game ZIP file from the [Releases](https://github.com/Alijamal-web/Runner/releases) section.
2. Extract all files into a folder.
3. Keep all extracted files and folders together.
4. Run the game executable to start the game.
